要素作業時間 ビデオ起こし

林業機械作業を撮影した動画を見ながら、要素作業ごとの開始・終了時刻を記録し、Excel で集計できる形に書き出すツールです。インストールは不要で、ブラウザで開くだけで使えます。

ダウンロード

HTML ツール本体 ダウンロード CSV 作業区分の見本（チェーンソー伐木造材） ダウンロード

使い始めるまで

  1. 上の2つのファイルを、同じフォルダに保存します。
  2. ツール本体（HTML）を Chrome または Edge で開きます。ダブルクリックで開けない場合は、ブラウザの画面にファイルをドラッグしてください。
  3. 画面下部の［作業区分の編集］を開き、［CSVを読込］で見本の CSV を読み込みます。現場に合わせて作業区分を書き換え、［作業区分を保存（CSV）］で残しておくと次回から使えます。
  4. ［動画を選ぶ］で動画を読み込み、［観測開始］から記録を始めます。

注意

  • 再生できる動画は MP4・MOV・WebM です。古いビデオカメラの .mpg は、HandBrake などで MP4 に変換してから使ってください。
  • 記録は同じPC・同じブラウザ内に自動保存されますが、別のPCやブラウザには引き継がれません。区切りのよいところで［作業ファイルを保存］を押し、動画と同じフォルダに残してください。
  • ツール本体のファイル名を変えると、それまでの自動保存は読み込まれなくなります（作業ファイルは影響を受けません）。
